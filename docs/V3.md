## Liga TV (transmisiones .m3u8)

Se controla en vivo desde Firebase, sin publicar otra versión de la app:

1. Firebase Console → Firestore → colección `app_config` → documento `liga_tv`
2. Campos:

| campo | tipo | ejemplo |
|---|---|---|
| active | boolean | true |
| hlsUrl | string | https://tu-servidor/live/index.m3u8 |
| title | string | La Previa · Jornada 22 |
| subtitle | string | Analizamos el clásico |
| poster | string | https://…/poster.jpg |
| startsAt | timestamp | próxima transmisión (cuenta regresiva + "Avísame") |
| hosts | array | ["Alejo", "Invitado"] |
| chatEnabled | boolean | true |

3. Publica las reglas de `docs/firestore.rules` (chat seguro).

Con `active: true`, el Home muestra el banner rojo "LIGA TV EN VIVO" y la pantalla abre el reproductor con chat. Con `active: false` y `startsAt` en el futuro, muestra la cuenta regresiva.

## Identidad visual "La Diagonal" (aprobada)

Sale del escudo oficial: azul `#3568FD` → `#36A0FF` y la diagonal blanca.

- **Firma:** la diagonal (`SLASH_SKEW = -20deg`) aparece en títulos de sección (`<Slash/>`), el marcador `2 / 1` (`<ScoreSlash/>`), chips activos, indicador de pestañas y barra inferior, zonas de la tabla, racha y barras de estadísticas.
- **Fotos:** estadios en duotono azul + haces diagonales (`<StadiumBackdrop/>`). En el partido se usa `stadium.image` de `match-center.php`.
- **Color:** azul noche `#060A17` de fondo; el rojo `#FF3B4E` solo para "en vivo" y descenso.
- **Tipografía:** Inter (texto) + Inter Display (titulares y números tabulares). Licencia OFL, en `assets/fonts` (recortadas a latín, 480 KB).
- **Partidos:** formato de liga oficial (local izquierda · hora/marcador al centro · visitante derecha), agrupados por día con bloque EN VIVO arriba.

## Fase 3 · Juegos

| Juego | Pantalla | Datos |
|---|---|---|
| Quiniela de la jornada | `QuinielaScreen` | Firestore `quiniela_predictions` + resultados de `matches.php` |
| Ranking nacional / Ligas con amigos | `RankingScreen` | Firestore `quiniela_scores`, `quiniela_leagues` |
| ¿Quién es el jugador? | `DailyPlayerScreen` | `scorers.php` (todo en el teléfono, racha local) |

**Puntos de la quiniela:** exacto 5 · ganador + diferencia 3 · ganador 2 · fallo 0. Se puede cambiar el pronóstico hasta el pitazo de cada partido.

### Activar en Firebase (una sola vez)
1. **Authentication → Método de acceso → Anónimo**: habilitado (la app ya lo usa para el chat).
2. **Firestore → Reglas**: publicar `docs/firestore.rules`.
3. **Firestore → Índices**: crear los de `docs/firestore.indexes.json` (o `firebase deploy --only firestore:indexes`). Si falta alguno, la app sigue funcionando y Firebase muestra en el log un enlace para crearlo con un clic.

### Límite conocido
Los puntos se calculan en el teléfono y se publican en `quiniela_scores`. Las reglas impiden pronosticar después del pitazo, editar a otros y puntajes imposibles, pero un usuario avanzado podría inflar su total. Para un ranking con premios, el cálculo debe pasar al servidor: un endpoint PHP en el Núcleo (`quiniela-score.php`) que lea `quiniela_predictions` y los resultados oficiales y escriba `quiniela_scores` con una cuenta de servicio.

## En vivo (Liga TV) · cómo operarlo desde Firebase

**Pestaña "En vivo"** en la barra inferior (punto rojo cuando están al aire).

`app_config/liga_tv` (transmisión actual):

| campo | uso |
|---|---|
| `active` | `true` = al aire (muestra reproductor, reacciones y chat) |
| `hlsUrl` | Enlace de la señal. Si termina en `.m3u8`/`.mp4` usa nuestro reproductor nativo; si es una página (ej. `https://relay.../player/canal.html`) se abre en un reproductor web con controles propios (volumen, recargar, pantalla completa horizontal) |
| `playerUrl` | (opcional) Alternativa a `hlsUrl` para enlaces de página |
| `title`, `subtitle`, `poster`, `hosts` | datos de la emisión |
| `startsAt` | próxima emisión (cuenta regresiva + "Avísame") |
| `pinned` | mensaje fijado arriba del chat (ej. "Comenta con #ClasicoChapin") |
| `admins` | lista de `uid` de los conductores: sus mensajes salen con insignia "Liga TV" |
| `chatEnabled` | `false` para apagar el chat |

`liga_tv_shows/{id}` (programación y episodios):
`title`, `description`, `poster`, `startsAt` (timestamp), `hosts`, `vodUrl` (opcional, `.m3u8` o `.mp4` para "volver a ver").
Los futuros salen en **Programación** con "Avísame"; los pasados con `vodUrl` salen en **Episodios anteriores**.

Reacciones: `liga_tv_reactions/main` (contadores; la app los crea sola).

## En vivo — chat y anuncios

- **Chat de la previa:** con `chatEnabled: true` el chat está disponible aunque `active` sea `false`; la plática sigue en el mismo canal (`streamId: main`) cuando arranca la transmisión.
- **Anuncios en el reproductor:** al tocar volumen, pantalla completa, ventana flotante o recargar se intenta mostrar un intersticial (máx. 1 por minuto y 8 por sesión, según `ads/AdManager`).
- **Derechos:** retransmitir la señal de un canal de TV sin permiso puede provocar que Google Play / App Store retiren la app. Usa señales propias o con autorización.


## Notificaciones automáticas (push) — gratis con FCM

La app ya se suscribe sola a los temas `match_{id}` (al tocar "Recordarme"), `team_{id}` (al seguir un club) y `liganacionalgt` (todos).
`services/push-watcher.js` vigila nuestra API y envía:

| Evento | Quién lo recibe |
|---|---|
| 📋 Alineaciones confirmadas (antes del partido) | quien sigue el partido o a alguno de los equipos |
| 🟢 Arrancó · ⏸️ Medio tiempo · ▶️ 2º tiempo | ídem |
| ⚽ Gol (goleador, minuto y marcador) · 🏁 Final | ídem **+ todos** (configurable con `GLOBAL_EVENTS`) |
| 🟥 Expulsión | quien sigue el partido o los equipos |

Cada persona recibe **una sola** notificación aunque siga partido y equipo. Al tocarla abre el partido (las alineaciones abren su pestaña).

**Instalar en el servidor donde corre `services/server.js`** (Node 18+, misma `serviceAccountKey.json`):
```bash
cd services
npm i firebase-admin dotenv        # si no están
DRY_RUN=1 node push-watcher.js     # prueba: imprime lo que enviaría
pm2 start push-watcher.js --name lngt-push-watcher && pm2 save
```
Revisa la API cada 20 s cuando hay partido cerca y cada 5 min cuando no. Al reiniciar no repite notificaciones (`push-state.json`).

## Publicar en Google Play (sin tocar código)

- `targetSdkVersion = 36` (Android 16) ya está puesto. `versionCode` se genera solo con la fecha/hora de compilación, así que **nunca hay que cambiarlo a mano**.
- Generar el paquete: `cd android && ./gradlew clean bundleRelease` → `android/app/build/outputs/bundle/release/app-release.aab`.
- Play Console → **Producción → Crear versión → subir el .aab → Guardar → Revisar → Enviar a revisión**.
- Solo cambia `versionName` en `android/app/build.gradle` si quieres que los usuarios vean otro número (ahora `6.0.0`).
