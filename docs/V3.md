## Arquitectura nueva (`src/`)

```
src/
  design/      tokens.js (color, tipo, espacio, motion) · useDesign()
  ui/          Kit base: Txt, Surface, PressableScale, LiveBadge, TeamCrest,
               Skeleton, SectionHeader, Pill, Empty/Error/Offline states
  api/         client.js   → HTTP con timeout, reintentos y deduplicación
               store.js    → caché stale-while-revalidate persistente + polling
               liga.js     → endpoints y hooks (useHome, useMatches, useStandings…)
               normalize.js→ modelos estables para la UI
               clock.js    → reloj en vivo, cuenta regresiva, formatos de fecha
               logoRegistry.js → logos oficiales por teamId
  features/    matches · standings · scorers · season · ligatv
  notifications/reminders.js → notificaciones locales (Notifee)
  screens/     HomeScreen · LigaTVScreen
```

Regla: las pantallas nuevas **no** usan `fetch` ni colores directos. Todo pasa por `src/api` y `useDesign()`.

## Liga TV (transmisiones .m3u8)

Se controla en vivo desde Firebase, sin publicar otra versión de la app:

1. Firebase Console → Firestore → colección `app_config` → documento `liga_tv`
2. Campos:

| campo | tipo | ejemplo |
|---|---|---|
| active | boolean | true |
| hlsUrl | string | https://tu-servidor/live/index.m3u8 |
| title | string | La Previa · Jornada 22 |
| subtitle | string | Analizamos el clásico |
| poster | string | https://…/poster.jpg |
| startsAt | timestamp | próxima transmisión (cuenta regresiva + "Avísame") |
| hosts | array | ["Alejo", "Invitado"] |
| chatEnabled | boolean | true |

3. Publica las reglas de `docs/firestore.rules` (chat seguro).

Con `active: true`, el Home muestra el banner rojo "LIGA TV EN VIVO" y la pantalla abre el reproductor con chat. Con `active: false` y `startsAt` en el futuro, muestra la cuenta regresiva.

## Fase 2 · Partido, equipo y jugador

| Pantalla | Archivo | Datos |
|---|---|---|
| Match Center | `src/screens/MatchCenterScreen.js` | `match-center.php` (cada 10 s en vivo) |
| Perfil de equipo | `src/screens/TeamProfileScreen.js` | `team.php`, `teams.php`, `matches.php`, `standings.php`, `scorers.php`, `players.php?team_id=` |
| Perfil de jugador | `src/screens/PlayerProfileScreen.js` | `player.php`, `scorers.php` |

- **Match Center:** pestañas Resumen (línea de tiempo + votación), Alineaciones (cancha con formación, tarjetas, goles y cambios sobre cada jugador), Estadísticas (barras animadas) y Previa (forma, H2H, goleadores, tabla en vivo). Abre en Previa si el partido no ha empezado.
- **Campana del partido:** suscribe al push del servidor (tema `match_{id}`) y programa el aviso local 15 min antes.
- **Equipo:** el color de la cabecera sale del escudo automáticamente. "Seguir equipo" usa el contador de Firestore y el tema `team_{id}`.
- **Cancha:** si el Núcleo envía `fieldX`/`fieldY` (0–100) se usan esas posiciones; si no, se ubica por la formación.
- Las pantallas antiguas (`components/Match.js`, `TeamScreen.js`, `PlayerScreen.js`) ya no están en la navegación; se borran cuando la v3 quede validada.

## Identidad visual "La Diagonal" (aprobada)

Sale del escudo oficial: azul `#3568FD` → `#36A0FF` y la diagonal blanca.

- **Firma:** la diagonal (`SLASH_SKEW = -20deg`) aparece en títulos de sección (`<Slash/>`), el marcador `2 / 1` (`<ScoreSlash/>`), chips activos, indicador de pestañas y barra inferior, zonas de la tabla, racha y barras de estadísticas.
- **Fotos:** estadios en duotono azul + haces diagonales (`<StadiumBackdrop/>`). En el partido se usa `stadium.image` de `match-center.php`.
- **Color:** azul noche `#060A17` de fondo; el rojo `#FF3B4E` solo para "en vivo" y descenso.
- **Tipografía:** Inter (texto) + Inter Display (titulares y números tabulares). Licencia OFL, en `assets/fonts` (recortadas a latín, 480 KB).
- **Partidos:** formato de liga oficial (local izquierda · hora/marcador al centro · visitante derecha), agrupados por día con bloque EN VIVO arriba.
