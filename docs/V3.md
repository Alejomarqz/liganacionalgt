# Liga Nacional GT · App v3

## Arquitectura nueva (`src/`)

```
src/
  design/      tokens.js (color, tipo, espacio, motion) · useDesign()
  ui/          Kit base: Txt, Surface, PressableScale, LiveBadge, TeamCrest,
               Skeleton, SectionHeader, Pill, Empty/Error/Offline states
  api/         client.js   → HTTP con timeout, reintentos y deduplicación
               store.js    → caché stale-while-revalidate persistente + polling
               liga.js     → endpoints y hooks (useHome, useMatches, useStandings…)
               normalize.js→ modelos estables para la UI
               clock.js    → reloj en vivo, cuenta regresiva, formatos de fecha
               logoRegistry.js → logos oficiales por teamId
  features/    matches · standings · scorers · season · ligatv
  notifications/reminders.js → notificaciones locales (Notifee)
  screens/     HomeScreen · LigaTVScreen
```

Regla: las pantallas nuevas **no** usan `fetch` ni colores directos. Todo pasa por `src/api` y `useDesign()`.

## Liga TV (transmisiones .m3u8)

Se controla en vivo desde Firebase, sin publicar otra versión de la app:

1. Firebase Console → Firestore → colección `app_config` → documento `liga_tv`
2. Campos:

| campo | tipo | ejemplo |
|---|---|---|
| active | boolean | true |
| hlsUrl | string | https://tu-servidor/live/index.m3u8 |
| title | string | La Previa · Jornada 22 |
| subtitle | string | Analizamos el clásico |
| poster | string | https://…/poster.jpg |
| startsAt | timestamp | próxima transmisión (cuenta regresiva + "Avísame") |
| hosts | array | ["Alejo", "Invitado"] |
| chatEnabled | boolean | true |

3. Publica las reglas de `docs/firestore.rules` (chat seguro).

Con `active: true`, el Home muestra el banner rojo "LIGA TV EN VIVO" y la pantalla abre el reproductor con chat. Con `active: false` y `startsAt` en el futuro, muestra la cuenta regresiva.

## Notificaciones locales (gratis)

- La campana del partido destacado programa un aviso 15 min antes (funciona sin internet).
- La pantalla Liga TV programa un aviso 5 min antes de la transmisión.
- El push de Firebase (FCM) sigue igual para goles y alertas del servidor.
